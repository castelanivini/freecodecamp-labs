# Especificação - Basic Arithmetic Operations

## Objetivo

Criar um programa em JavaScript que realiza operações matemáticas básicas utilizando variáveis e operadores aritméticos.

---

## Requisitos Funcionais

### 1. Soma

- [ ] Criar uma variável chamada `firstResult`.
- [ ] Somar os números **5** e **10**.
- [ ] O resultado deve ser **15**.

---

### 2. Subtração

- [ ] Criar uma variável chamada `secondResult`.
- [ ] Subtrair **5** de **8**.
- [ ] O resultado deve ser **3**.

---

### 3. Soma com Correção de Valor

- [ ] Criar uma variável chamada `thirdResult`.
- [ ] A expressão deve resultar em **6**.
- [ ] Substituir o valor booleano existente na expressão por um número.

---

### 4. Segunda Soma com Correção

- [ ] Criar uma variável chamada `fourthResult`.
- [ ] A expressão deve resultar em **8**.
- [ ] Substituir o valor booleano existente na expressão por um número.

---

### 5. Multiplicação

- [ ] Criar uma variável chamada `fifthResult`.
- [ ] A expressão deve resultar em **20**.
- [ ] Substituir a string existente na expressão por um número.

---

### 6. Soma com Valor Nulo

- [ ] Criar uma variável chamada `sixthResult`.
- [ ] A expressão deve resultar em **22**.
- [ ] Substituir o valor `null` existente na expressão por um número.

---

# Critérios de Aceitação

O programa será considerado concluído quando:

- [ ] `firstResult` possuir o valor **15**.
- [ ] `secondResult` possuir o valor **3**.
- [ ] `thirdResult` possuir o valor **6**.
- [ ] `fourthResult` possuir o valor **8**.
- [ ] `fifthResult` possuir o valor **20**.
- [ ] `sixthResult` possuir o valor **22**.
- [ ] Todos os resultados forem obtidos utilizando operadores aritméticos.

---

- Operador de multiplicação (`*`)
